# 하루전기 — 검증 중인 별도 시험판

이 브랜치는 기존 My Cabin에서 분기했으며 Android에서 web/ev-day.html을 엽니다. 실제 Pleos 서비스 연결, 음성 인식, 경로 검색, 날씨·운전 습관 학습과 추정 정확도 검증은 미구현입니다. 값은 수동 입력입니다. 기존 My Cabin README와 APK는 이 시험판의 설명·결과물이 아닙니다.

## 계산
주행 에너지(kWh) = 거리(km) / 전비(km/kWh). 정차 에너지(kWh) = 시간(h) × 평균 부하(kW). 종료 SOC(%) = 시작 SOC − 총 사용 에너지 / 입력한 사용 가능 용량 × 100. 실제 충전, 온도, 공조, 열화, 경사, 교통 변동 등을 반영하지 않습니다. 검증되지 않은 계산을 주행 가능성이나 충전의 안전 근거로 삼을 수 없습니다.

## 실행
브라우저: 저장소 루트에서 python -m http.server 8080 --directory web 실행 후 /ev-day.html을 엽니다. Android: GitHub Actions에서 해당 커밋의 빌드 및 Android 에뮬레이터 결과를 확인합니다. 개발용 임시 서명 키는 배포용이 아닙니다.

공모전용 최종 APK·영상은 별도 제작 및 검증 필요. 기존 My Cabin 자료로 대체하면 안 됩니다.
