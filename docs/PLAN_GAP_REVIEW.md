## 제출 전 정합성

- 신청서의 Kotlin 개발 계획과 현재 Java Android 코드의 차이를 설명하거나 문구를 수정합니다. 공식 개발 환경은 Java와 Kotlin을 모두 허용합니다.
- 신청서의 Pleos TTS/STT 사용은 계획이며 현재는 Android TTS/SpeechRecognizer 코드입니다.
- 실제 주행 상태 연동과 실차 제어가 검증됐다고 표현하지 않습니다.
- 시험된 APK·소스·영상과 최종 제출 커밋을 일치시키고 최종 커밋의 검증 결과를 확인합니다. 기존 APK는 별도 서명되어 있으며 일반 AVD에서의 실행 기록은 이전 커밋 기준입니다.
- 영상에서는 일반 Android 에뮬레이터 녹화와 화면 목업을 명확히 구분하고, 모의 차량 설정을 실제 제어로 표현하지 않습니다.
- Pleos 에뮬레이터 버전과 실제 앱 영역 화면 규격은 실행 후 측정하여 기록합니다.
- 숏폼은 30초~1분 세로 영상으로 제작해 Instagram Reels 또는 YouTube Shorts에 게시하고 필수 해시태그 #HMG차량용앱개발공모전 포함 2~3개를 사용합니다. 게시 링크를 신청서 8번에 기재합니다.
