# 90초 시연 순서

## 준비

APK 설치 후 My Cabin을 엽니다. 화면 설정에서 초기화하면 처음 데이터로 돌아옵니다. 시연용 자료만 사용하세요. 기본 흐름은 모의 차량으로 동작하며 실차 동작을 보여주는 시연이 아닙니다.

| 시간 | 화면·동작 | 보여줄 가치 |
|---|---|---|
| 0~7초 | 홈의 학습/휴식/수면/식사 | 하나의 앱에서 목적 선택 |
| 7~20초 | 휴식 → 20분 휴식 → 편집 | 기본 마이씬도 사용자 취향에 맞게 변경 |
| 20~32초 | 이름·온도·밝기 수정 → 저장 | 취향의 저장과 재사용 |
| 32~45초 | 시작 → 모의 적용 → 타이머 | 한 번 선택으로 준비하는 개인 공간 |
| 45~52초 | 종료 → 이전 모의 설정 복원 | 다음 이동을 위한 정리 |
| 52~65초 | 학습 → 여행 영어 → 듣기·다음 | 차 안의 시간을 학습으로 활용 |
| 65~75초 | 목록 복귀 → 이어서 학습 | 이전 구간 자동 복원 |
| 75~83초 | 새 학습자료 등록 | 본인이 선택한 자료로 확장 |
| 83~90초 | D 시연에서 수면 시작 제한, 식사 마이씬 | 상황에 맞는 사용 흐름 |

실제 SDK 연결은 위 흐름과 별도로 설정 → 지원 기능 조회에서 확인합니다. 서비스·주차 판정·권한 미충족 시 쓰기 잠금은 정상 처리입니다. 실제 시트가 움직였다는 연출을 만들지 않습니다.

## 실제 APK 실행 녹화

`media/MyCabin_APK_Demo.mp4`는 일반 Android 14 AVD에서 **제출 release APK를 실제 실행**한 약 84초 화면 녹화입니다. 편집 화면에서 저장하기, 모의 휴식 시작·종료·복원, 학습 구간 이동·이어가기를 보여 줍니다. `MyCabin_Android_AVD_Raw.mp4`는 원본입니다. Pleos 전용 AVD가 아니며 SDK 차량 제어·AI 실응답을 검증하는 녹화가 아닙니다.

## 목업 영상 파일

- `media/MyCabin_Prototype_Demo.mp4`: DOM 렌더 기반 기능 흐름 영상. 무음·한글 자막형
- `media/MyCabin_Shortform.mp4`: 세로 45초 숏폼 초안. 무음·한글 자막형

두 파일 모두 원본 자료를 캡처한 뒤 화면을 편집한 목업 영상이며 실제 APK/AVD 화면 녹화가 아닙니다. SDK·마이크·AI 네트워크 실행이 성공한 장면은 포함하지 않았습니다. 실제 환경 검증 후 에뮬레이터 녹화본으로 교체할 수 있습니다.

숏폼 특별상에 출품하려면 대회 숏폼 안내의 플랫폼·태그·링크 요건을 다시 확인해 본인 계정으로 게시한 URL을 작성해야 합니다. 현재 MP4 파일만 만들어졌으며 SNS 게시·공개 URL 생성·공모전 접수 이메일 발송은 하지 않았습니다.
