# 마이캐빈 차량 실내 콘셉트 시연 구성안

이 문서는 **촬영·영상 제작을 위한 콘셉트 구성안**입니다. 영상이나 실차 검증 결과가 아닙니다. 미구현 기능과 SDK 검증 전 차량 변화는 화면 자막에 ‘콘셉트 시뮬레이션’으로 표시합니다.

## 영상 원칙

- 실제 설치 앱, Pleos 시스템 화면, 차량 실내 변화의 출처를 구분합니다.
- 차량 제어 장면에서는 카메라 구도를 고정하고 해당 동작이 완료된 이후에만 카메라를 움직입니다.
- 좌석·조명·공조 등은 독립된 동작으로 보여 줍니다. 지원 차량, 옵션, SDK 권한 및 실제 테스트 여부에 따라 적용 범위가 달라집니다.
- 차량 페달·제동장치·구동계를 비활성화하는 연출은 넣지 않습니다. 앱에서 제어할 수 있다고 단정하지 않습니다.
- 화면에 보이는 모든 조작은 운전자가 안전하게 주차한 장면으로 구성합니다. 주행 중 화면 조작을 권하는 연출은 사용하지 않습니다.

## 제안 장면

| 장면 | 화면과 카메라 | 제시할 내용 및 상태 |
|---|---|---|
| 1. 차량 시작 | 실제 Pleos 시스템 또는 구분 표시한 목업. 고정 화면에서 시스템 앱 목록 열기 | 차량 시스템이 앱 목록을 제공하고 My Cabin을 선택하는 흐름 |
| 2. 학습 선택 | 차량 화면을 고정 촬영. 학습 모드 선택 | 최근 학습과 이어듣기. 음성 대화는 실제 확인된 입력·응답만 사용하거나 콘셉트로 표시 |
| 3. 휴식 시작 | 정차 상태 표시와 모드 선택 화면 | 차량과 사용자 확인 조건을 먼저 보여 줌 |
| 4. 좌석 | 좌석이 보이도록 카메라 고정 | 지원 차량의 좌석 메모리 이동을 촬영하거나 별도로 ‘콘셉트 시뮬레이션’ 표시. 이동 완료를 확인한 뒤 다음 화면 |
| 5. 조명 | 같은 고정 구도 | 밝기 변화가 완료된 뒤 다음 장면. 실제 SDK 지원과 검증 상태 구분 |
| 6. 공조·소리 | 화면 고정, 공조 설정 표시와 오디오 | 온도·풍량·환경음 중 실제 지원된 항목만 시연. 공기 흐름은 실제 값 확인 또는 콘셉트 표시 |
| 7. 수면 | 좌석과 조명 변화는 각각 고정 구도로 나눔. 이후에만 부드러운 실내 이동 촬영 | 주차 확인, 타이머, 종료 후 사용자의 자세 복원 선택 |
| 8. 식사 | 정차 상태에서 좌석 공간, 조명, 공조를 차례로 고정 촬영 | 실제 차량과 저장된 메모리가 허용하는 범위에서 구현. 좌석을 항상 최대 후방 이동한다고 가정하지 않음 |
| 9. 마무리 | 앱의 모드 선택 화면과 차량 내부를 순서대로 노출 | 실제 구현·모의·향후 계획을 나누어 표기 |

## 실제 제작 전에 확인할 것

1. 공식 Pleos 에뮬레이터 또는 차량에서 앱 목록 노출과 화면 크기를 확인합니다.
2. 실제 사용 가능 차량에서 각 기능의 capability, 권한, 적용 결과 및 복원 결과를 기록합니다.
3. 학습 대화는 실제 음성 인식 및 합성 서비스가 작동할 때 직접 녹음합니다. 합성 음성·영상은 출처와 구현 여부를 표시합니다.
4. API 또는 차량에서 확인되지 않은 항목은 미래 구상으로만 보여 줍니다.
5. 화면 녹화, 실제 차량 촬영, 합성 영상을 혼합할 경우 각 장면의 출처가 오해되지 않도록 표기합니다.
