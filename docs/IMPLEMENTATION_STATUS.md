## 실제 연동 경로

일반 UI → MockVehicleGateway는 화면 시연용입니다. 설정의 SDK 패널 → Java PleosVehicleGateway는 별도 경로입니다. SDK 초기화 요청만으로 연결 성공을 표시하지 않습니다. capability 응답, SET ACK, GET readback을 각각 기록합니다. 여러 설정의 원자적 적용·자동 롤백을 보장하지 않습니다. 실제 주차 판정 실패 시 제어 요청은 잠깁니다.

## 다음 실행 검증에서 확인할 사항

1. 전용 AVD의 버전·Vehicle Service 버전·실제 화면 규격 기록
2. APK 설치·첫 화면·영속 저장·WAV/TTS 실제 재생 확인
3. 마이크 권한 거절·인식 서비스 부재·인식 성공 경로 확인
4. HVAC/Light/Seat capability 지원 범위·주차 상태 API 권한 확인
5. 쓰기 지원 환경에서 공조/밝기 readback, 좌석 요청 결과 개별 확인
6. 실제 주행 상태에서 기능 접근 제약을 플랫폼 UX 규칙에 맞춰 검증. 현재 일반 UI의 P/D는 테스트 입력이며 실차 주행 상태를 자동 추적하지 않으므로, 실차 운전자용 배포 전 상태 구독 및 플랫폼 주행 제한 연동이 필요함
7. 본인 AI 서버를 HTTPS로 연결해 원문 전송 동의·모델 오류·실제 생성 설명 확인
